# Seven Tides : les téléchargements

Seven Tides est un jeu de survie gratuit. Un avion de ligne s'écrase sur une île. Il faut fouiller l'épave, faire du feu et tenir sept nuits jusqu'au navire du huitième matin.

**Site du jeu : https://seven-tides.netlify.app**

Ce dépôt ne contient pas le code du jeu. Il sert seulement à héberger les fichiers à télécharger, dans l'onglet [Releases](https://github.com/JeanBsh/seven-tides-releases/releases) :

- `SevenTides-Setup.exe` : l'installeur pour Windows 10 et 11, en 64 bits ;
- `SevenTides-macOS.dmg` : l'application pour les Mac à puce Apple, sous macOS 12 ou plus récent.

Les fichiers ne sont pas signés. Au premier lancement, Windows et macOS affichent donc un avertissement. La page [Télécharger](https://seven-tides.netlify.app/telecharger/) explique comment ouvrir le jeu malgré cet avertissement. Elle donne aussi l'empreinte SHA-256 de chaque fichier, pour vérifier qu'il n'a pas été modifié.

Le jeu est distribué gratuitement sous la [licence d'utilisation](https://seven-tides.netlify.app/licence/) de son éditeur, Jean-baptiste Boshra.
